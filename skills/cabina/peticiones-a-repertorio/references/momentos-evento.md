# Momentos criticos por tipo de evento

Sirve para ordenar la lista de compra por criticidad (Paso 4) y para agrupar
las peticiones del cliente. Un track de momento critico se compra siempre; uno
de ambiente puede sustituirse por equivalente de biblioteca.

## Boda

| Momento | Criticidad | Nota operativa |
|---|---|---|
| Entrada de ceremonia | Critico | Suele ser eleccion cerrada del cliente, sin sustituto |
| Firma / registro | Medio | Instrumental o version sin voz |
| Salida de ceremonia | Critico | Alta energia, eleccion cerrada |
| Coctel / aperitivo | Bajo | Ambiente, sustituible |
| Entrada al banquete | Alto | Eleccion del cliente, con nombre propio |
| Primer baile | Critico | Version y duracion exactas importan; confirmar edicion |
| Baile con padres | Critico | Suele ser el track mas emocional; nunca improvisar |
| Ramo / liga | Medio | Convencional, sustituible |
| Apertura de pista | Alto | Define si la pista arranca o no |
| Cierre | Alto | Eleccion del cliente en la mitad de los casos |

## Corporativo

| Momento | Criticidad | Nota operativa |
|---|---|---|
| Recepcion | Bajo | Ambiente, volumen bajo |
| Entrada de directivo / premio | Critico | Marca aprobada, sin margen |
| Video corporativo | Critico | Puede requerir licencia distinta |
| Cena | Bajo | Ambiente |
| Barra libre | Medio | Aqui manda la lista de prohibidos de marca |

## Quinceanera

| Momento | Criticidad | Nota operativa |
|---|---|---|
| Entrada | Critico | Coreografia ensayada: version y duracion exactas |
| Vals | Critico | Coreografia ensayada; cualquier edit distinta rompe el baile |
| Cambio de zapatilla | Alto | Track con nombre propio |
| Baile sorpresa | Critico | Coreografia; a veces con edit propio que aporta el cliente |
| Fiesta | Medio | Aqui entra el grueso de peticiones de invitados |

## Regla de version por momento

- Coreografia ensayada (vals, primer baile, baile sorpresa): la version y su
  duracion son parte del contrato. Si el cliente ensayo con una edicion
  concreta, cualquier otra rompe el baile. Confirmar duracion en segundos.
- Publico familiar o menores presentes: version Clean por defecto.
- Bloque de baile largo: Extended cuando exista.
- Ceremonia: evitar Extended con intro larga de percusion.
