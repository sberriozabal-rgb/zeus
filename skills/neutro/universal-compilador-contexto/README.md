# universal-compilador-contexto v1.1.0

**Qué hace.** Lee la carpeta de cualquier proyecto (ordenador, Drive o ZIP) y los chats
del proyecto, y entrega UN ZIP con: biblioteca de contexto por dominios (taxonomía
derivada del material), resumen ejecutivo, resumen de todos los chats, resumen de
contexto (1 página) e inventario con ubicación de cada documento.

**Cuándo sí.** Primera compilación, recompilación, «qué decidimos en los chats», «qué
documentos tenemos y dónde», poner orden en una documentación dispersa.

**Cuándo no.** Redactar entregables u opinar sobre el proyecto; cifrar y migrar a otra
cuenta (`respaldo-proyecto-ia-cl`, que recibe este ZIP).

**Entrada.** Carpeta del proyecto + nombre del proyecto + (opcional) export oficial de chats.
**Salida.** `<PROYECTO>_CONTEXTO_<fecha>.zip` + maestros cargados al proyecto.

**Uso rápido.** «Compila la carpeta X al proyecto» · «hazlo directo» salta la aprobación del censo.
