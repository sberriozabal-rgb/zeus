# Skills externas

Skills de terceros descargadas para uso interno de la casa. **No forman parte del
catálogo de venta** (`CATALOGO.md`) ni cuentan para las 17 piezas en `ACORDADO`: tienen
autor y licencia ajenos y no se pueden empaquetar ni revender.

| Skill | Origen | Licencia | Uso |
|---|---|---|---|
| `omnivoice` | [debpalash/VoiceStudio](https://github.com/debpalash/VoiceStudio) | AGPL-3.0-only | TTS local, clonación de voz, STT, doblaje |

Cada carpeta es un enlace a la copia real en `.claude/skills/<nombre>/`, que es la que
Claude Code carga al abrir este repositorio. La ficha de procedencia de cada una está en
su `ORIGEN.md`.
